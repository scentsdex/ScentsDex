# Free on-device bottle editor

The editor downloads a small U2-Netp segmentation model and ONNX Runtime Web. Bottle pixels remain in the browser until the admin publishes the finished JPEG to the existing Supabase bucket. An official product image may be fetched with CORS; when its server prevents that, the selected local photo is used and the preview names that source. No paid image service or generative image API is used.

The 320px segmentation mask can have artifacts on transparent glass or complex photos. Review the preview. Only the background, placement and shadow are changed. A deterministic multi-tone backdrop varies by perfume identity. This is not the generative scene-editing process used for the initial five editorial images.
