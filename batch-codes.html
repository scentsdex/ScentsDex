Where’s the code?

Look underneath the bottle or on the bottom flap of the box. It may be printed, engraved, or pressed into the packaging.

A batch code is separate from the long barcode. Keep similar characters in mind: O and 0, I and 1.

Dates tell part of the story.
A batch code does not verify authenticity or determine expiry.

Before you search

A few things to know.

Which brands can I check?

This first version estimates certain modern formats for Azzaro, Giorgio Armani, Lancôme, Mugler, Prada, Ralph Lauren, Valentino, Yves Saint Laurent, Dior, and Guerlain. L’Oréal-style codes cover 2020–2026, with the A = 2026 year mapping inferred from the public letter cycle; the modern Dior / Guerlain convention covers 2018–2027. Historical codes, different factories, and former license holders may use other formats. Other brands can be entered, but will return “Date unavailable” until a checked rule is added.

How accurate is the manufacture date?

Results are estimates of a month and year from public conventions, rather than confirmation from the brand. Some codes repeat across decades. The day is not determined by these rules. If you need an exact date or your bottle may be older, contact the manufacturer with photos of the bottle, box, and code.

Why didn’t my code return a date?

The brand or code format may not be supported yet. Check the brand, every character, and that you entered a batch code rather than a barcode. Unrecognized year letters and future dates return no estimate.

Can this tell me whether my perfume is genuine?

No. A readable code can appear on both genuine and counterfeit packaging. This tool only estimates a production period for supported codes.
